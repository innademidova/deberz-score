# Деберц — счёт (PWA)

Сайт без сервера: всё хранится в localStorage телефона, после первого открытия работает без интернета.

## Проверка
```
node --test tests/scoring.test.mjs     # проверки правил подсчёта
node tests/simulate.mjs 200            # эмуляция 800 настоящих партий (колода, раздача, розыгрыш взяток), сверка очков
python3 -m http.server 8123            # локально: http://localhost:8123
```

## Публикация и установка (без магазинов приложений)
Нужен любой статический хостинг с https: GitHub Pages, Netlify, Cloudflare Pages — достаточно выложить эту папку.
- **Android (Chrome):** открыть сайт → меню ⋮ → «Установить приложение» / «Добавить на главный экран».
- **iPhone (Safari):** открыть сайт → «Поделиться» → «На экран “Домой”». Только в Safari. Установленное приложение хранит данные надёжнее, чем вкладка.
- Данные можно сохранить файлом (Команды → «Сохранить копию») и загрузить на другом телефоне.

При изменении файлов поднимите `VERSION` в `sw.js`, иначе телефон покажет старую версию из кеша.
